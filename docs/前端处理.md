# 一、为什么应该删除用户前端

你的 Next.js 前端目前承担：

* 展示机会列表
* 展示报告
* 用户查看数据
* Dashboard

但是这些能力飞书已经替代：

| 原功能       | 飞书替代    |
| --------- | ------- |
| 用户登录      | 飞书账号体系  |
| Dashboard | 飞书多维表格  |
| 报告页面      | 飞书文档    |
| 搜索        | 飞书知识库搜索 |
| 消息提醒      | 飞书Bot   |
| 用户互动      | 飞书聊天    |

继续维护 Web：

意味着：

* React 依赖
* UI维护
* 登录系统
* 权限系统
* 部署
* CDN
* 安全

这些与你赚钱没有直接关系。
